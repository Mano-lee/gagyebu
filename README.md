# 내 생활

가계부, 냉장고, 레시피를 한곳에서 사용하는 생활 플랫폼이에요. 처음 열면 **플랫폼 홈**에서 사용할 앱을 선택해요.

- **가계부**: 요약, 내역, 가계부 설정을 관리해요.
- **냉장고**: 보관 목록, 식재료 등록 대기, 소비·폐기 기록을 관리해요.
- **레시피**: 복사한 글·출처 링크·사진을 보관하고 재료·태그로 검색해요.
- **설정·백업**: 모든 앱의 구글 시트 연결과 백업을 함께 관리해요.

플랫폼 홈에는 **앱 아이콘과 이름만** 표시해요. 각 앱 상단의 **← 플랫폼 홈**으로 돌아올 수 있어요. 처리할 일이 있을 때만 홈 위쪽에 **앱별 알림**이 나타나요. 냉장고의 등록 대기·기한 임박·경과, 가계부의 확인할 고정지출·예정지출 알림을 누르면 해당 앱으로 바로 이동해요. 예산·보관 품목 수 등의 미리보기는 앱 안에서 확인해요. 휴대폰·브라우저의 뒤로 가기와 앞으로 가기도 지원해요. 앱 안에서 새로고침하면 해당 화면을 유지하고, 설치 앱을 기본 주소로 열면 플랫폼 홈에서 시작해요.

가계부 지출에서 식품을 체크하면 냉장고에 **식재료 등록 대기**가 생겨요. 제품별 금액을 나누지 않고 장보기 결제 한 건을 여러 식재료와 연결할 수 있어요.

### 레시피 사용하기

플랫폼 홈의 **레시피**를 열고 **레시피 추가**를 누르세요. 제목만 먼저 저장하거나, 출처 이름·링크·재료·조리 순서·태그·메모를 함께 기록할 수 있어요. 재료는 한 줄에 하나, 조리 순서는 한 줄에 한 단계씩 입력해요. 링크만 저장해 두고 나중에 내용을 채워도 됩니다.

- **텍스트**: **복사한 레시피 글 붙여넣기**를 펼쳐 원문을 붙여넣어요. **재료·조리 순서로 나누기**는 `[재료]`, `만드는 법`, `Ingredients`, `Instructions` 같은 제목을 기준으로 내용을 나눠요. 원문은 그대로 보관하므로 나눠진 내용을 확인하고 수정할 수 있어요. 제목이 없는 글은 원문 그대로 저장할 수 있어요.
- **링크**: 블로그·영상 등의 `http://` 또는 `https://` 주소와 출처 이름을 남겨요. 상세 화면의 **출처 열기**에서 다시 볼 수 있어요. 링크만으로 외부 사이트 본문을 자동 수집하지는 않아요.
- **사진**: 사진·스크린샷을 레시피당 최대 4장 첨부할 수 있어요. 한 장당 20MB 이하의 브라우저가 읽을 수 있는 이미지를 선택하세요. 긴 변 최대 1400px의 JPEG로 줄여 저장하므로 원본 파일은 따로 보관해 주세요. 사진 속 글을 자동으로 텍스트로 변환하지는 않아요. 상세 화면에서 사진을 누르면 크게 볼 수 있어요.

**분류**에는 한식·중식·일식·양식·동남아 요리·칵테일·음료·베이킹·디저트·기타를 추천해요. 목록에서 고르거나 `퓨전`, `나만의 요리` 같은 이름을 직접 입력할 수 있어요. 저장한 사용자 분류는 다음 입력에서도 추천되고, 레시피 목록과 상세 화면에 표시돼요. 비워 두거나 분류가 없는 예전 레시피는 **미분류**로 보여요. 기존 태그를 보고 자동으로 분류를 추측하지는 않아요. 분류는 레시피당 하나, 태그는 쉼표로 여러 개 지정할 수 있어요.

제목·재료·분류·출처·원문·태그 등을 검색하고, **분류·태그 필터를 함께 사용**하거나 최근 수정순·이름순으로 정렬할 수 있어요. 별을 누른 레시피는 **즐겨찾기**에 모여요. 상세 화면에서 **수정**을 누르면 내용 변경과 삭제가 가능해요. 휴대폰 뒤로가기는 입력창부터 닫고, 분류만 바꿨더라도 저장하지 않은 입력이 있으면 확인해요. 분류도 공통 백업·동기화·오프라인 저장에 포함돼요.

LLM에 정리를 부탁할 때는 기존 출력 양식의 제목 아래에 `분류: 칵테일` 같은 항목을 추가해 두세요. LLM이 출력한 분류는 앱의 **분류 입력칸**에 옮겨 적으면 돼요. 원문 나누기 기능은 기존처럼 재료·조리 순서를 나눠요.

레시피와 사진도 기존 공통 저장소, JSON 백업·복원, 구글 시트 동기화에 포함돼요. 오프라인에서도 저장한 내용과 사진을 볼 수 있어요. 사진이 쌓여 브라우저 저장 공간이 부족하면 입력창을 유지하고 저장 실패를 알려줘요. 사진을 줄이거나 백업 후 불필요한 레시피를 정리하세요. 레시피가 없는 예전 백업으로 복원하면 현재 레시피도 지워지므로 먼저 전체 백업을 받아두세요.

### 냉장고 사용하기

기한 입력 아래의 **1일·1주·1개월·3개월·6개월** 버튼은 **누를 때마다 현재 기한에 기간을 더해요.** 기한이 비어 있으면 구매일에서 시작해요. `1일` 두 번은 구매일 +2일, `1주` 후 `1일`은 +8일이에요. 버튼에 누른 횟수가 표시되고, **초기화**로 비운 뒤 다시 시작할 수 있어요. 개월은 현재 기한의 달력 날짜에서 더하며, 해당 날짜가 없는 달에는 마지막 날로 맞춰요. 구매일부터 누적한 경우 구매일을 바꾸면 같은 순서로 다시 계산해요. 기한을 직접 입력한 뒤 버튼을 누르면 그 날짜에서 더하고, 구매일을 바꿔도 직접 입력한 기준 날짜는 유지해요. 제품별로 따로 지정하고 포장에 표시된 기한도 확인해 주세요.

식재료 목록은 **이름·남은 수량·기한** 중심의 간단한 행으로 표시해요. 음식의 이름·수량·기한 영역을 누르면 **식재료 수정창**이 열려요. 가계부 연결은 유지하고, 처음 등록한 수량·연결된 장보기 정보는 수정창의 **추가 정보**를 펼쳐 확인해요. 구매 내역을 눌러 가계부 편집창으로 이동하는 목록 링크는 제거했어요. **− 1개 사용**, **− 1통 사용** 버튼은 별도로 눌러 수량을 하나씩 줄일 수 있어요. 마지막 수량을 사용하면 잔량 0으로 표시하고 **소비·폐기 기록의 다 먹음** 상태로 이동해요. 방금 사용한 수량은 알림의 **되돌리기**로 복원할 수 있고, 소비 기록에서도 보관 중으로 복원할 수 있어요. 되돌리기는 현재 화면 세션의 마지막 사용 한 건에 적용돼요.

가계부의 기록 추가·수정, 예정 지출 확정, 고정지출 추가·수정과 냉장고의 식재료 수정·등록창에서 **휴대폰의 뒤로가기**를 누르면 열린 창만 닫혀요. 가계부에서 보던 기간·탭·선택 날짜와 냉장고의 보관 장소 필터·검색어는 유지돼요. 아직 저장하지 않은 입력이 있으면 닫을지 확인해요. 취소하면 입력 내용이 유지되고, 저장·삭제·닫기 후에는 불필요한 이동 단계가 남지 않아요.

소분 식재료는 `고기 5팩`, 낱개 식품은 `계란 10개`처럼 실제로 먹는 단위로 등록하세요. 개·통·팩·봉·병 등은 한 번에 한 단위씩 사용하고, g·kg·ml·L처럼 무게나 부피로 기록한 재료는 **음식을 눌러 수정창의 남은 수량**을 바꿔요. 다 먹음·폐기도 수정창의 사용 상태에서 변경할 수 있어요. 기존 기록은 현재 저장된 수량부터 잔량 관리를 시작하며, 잔량과 소비 상태는 백업·동기화에 함께 포함돼요.

냉장고 화면 위쪽에서 **냉동실·냉장실 그림과 오른쪽 실온 박스**로 보관 상태를 한눈에 확인해요. 각 공간에 보관 중인 품목 수와 기한 상태가 표시돼요. **임박**은 표시 기한까지 3일 이내, **기한 지남**은 지난 날짜이며, 기한을 입력하지 않은 제품은 별도로 표시해요. 그림을 누르면 해당 보관 장소의 식재료 목록으로 이동해요. 소비·폐기한 제품은 보관 현황에서 제외하고, 수량이 여러 개인 제품도 등록된 묶음 하나를 1개 품목으로 세어요.

1. 지출을 기록하면서 구매한 식품의 **냉장·냉동·실온**을 체크해요. 여러 개를 선택할 수 있어요.
2. **플랫폼 홈** 상단의 알림이나 가계부 요약 화면에서 등록 대기를 확인해요. 냉장고 안의 **등록 대기** 메뉴에서도 볼 수 있어요. 이 알림은 앱 안에 표시돼요.
3. **식재료 등록하기**에서 제품 이름, 수량·단위, 보관 장소, 구매일, 표시된 기한을 입력해요. 구매일은 지출 날짜에서 가져와요.
4. **이 제품 저장하고 계속**으로 제품을 하나씩 저장해요. 중간에 닫아도 저장한 제품과 등록 대기는 남아요.
5. 모두 입력한 뒤 **등록 완료**를 눌러요. 실수로 체크했다면 **등록할 식재료 없음**으로 대기를 해제할 수 있어요.

같은 제품도 구매할 때마다 별도로 등록해 기한과 구매일을 구분해요. 이미 가지고 있는 재료는 **직접 등록**할 수 있어요. **다 먹음·폐기**를 처리하고, 소비·폐기 기록에서 보관 중으로 복원할 수 있어요. **임박은 오늘부터 3일 이내**이고, 지난 날짜는 **기한 지남**으로 따로 표시해요. **기한 임박·경과** 목록에는 두 종류를 함께 보여주며, 날짜를 입력하지 않은 제품은 제외해요.

지출의 날짜·메모를 수정해도 대기는 중복 생성되지 않아요. 완료한 구매에 새 보관 종류를 체크하면 다시 대기에 표시돼요. 지출을 삭제하거나 식품 체크를 해제해도 이미 등록한 식재료는 남아요. 백업·복원·초기화는 가계부와 냉장고에 함께 적용돼요. 예전 가계부 전용 백업을 복원하면 냉장고는 빈 목록이 됩니다.

### 기존 사용자 업데이트

사이트 파일에 `fridge.js`, `fridge.css`, `platform.js`, `platform.css`, `recipes.js`, `recipes.css`가 포함돼요. `index.html`, `sw.js`, `manifest.webmanifest`, 새 아이콘 파일과 함께 배포해요. 설치 앱의 표시 이름은 **내 생활**이에요.

**동기화를 사용한다면 아래 절차로 Apps Script 코드도 갱신하세요.** 기존 `SECRET` 비밀번호는 유지하고 [구글시트-동기화-코드.gs](구글시트-동기화-코드.gs)의 새 내용을 적용한 뒤, **배포 → 배포 관리 → 수정 → 새 버전**으로 배포해요. 이후 사용하는 모든 기기에서 앱을 새로고침해 주세요. 레시피를 포함한 데이터는 스키마 버전 4예요. 새 서버 코드는 버전 4 데이터가 저장된 뒤 레시피를 모르는 구버전 앱의 접근을 차단해 새 기록이 덮어써지는 것을 막아요. GitHub Pages 배포만으로 이 서버 보호가 갱신되지는 않아요. 구글 시트 원본과 JSON 백업에는 식재료·레시피·사진이 포함되고, 보기용 `내역` 탭에는 기존처럼 가계부 지출·수입이 표시돼요.

개발 검증: Node.js에서 `node --test tests/fridge.test.cjs`를 실행해요. Chrome 또는 Edge가 설치되어 있다면 `node tests/browser-check.cjs`로 실제 등록 흐름, 반응형 화면, 오프라인 새로고침을 검증할 수 있어요. 브라우저 검증은 별도 임시 프로필과 가상 데이터만 사용하고, 화면 이미지는 Git에서 제외된 `.qa-preview/`에 남겨요.

### 아이콘과 Git 배포

플랫폼 아이콘은 초록 바탕에 크림색·금색의 네 앱 타일을 배치한 [벡터 원본](app-icon.svg)이에요. 설치용 192·512px PNG, 아이폰용 180px PNG, 탭용 32px PNG를 함께 제공해요. 원본을 수정한 뒤 `node tests/browser-check.cjs --render-icons`로 다시 렌더링할 수 있어요.

기존 배포는 `Mano-lee/gagyebu`의 `main` 브랜치 루트를 사용하는 GitHub Pages예요. 이후 변경 시에는 로컬 검증 후 커밋·푸시하고, 배포된 버전과 실제 사이트까지 확인해요. 이 작업 순서는 [AGENTS.md](AGENTS.md)에 유지해요.

1. `node tests/deployment-check.cjs --inspect`로 기존 배포 상태·설정을 확인해요.
2. 자동 테스트, 로컬 브라우저 검증, `git diff --check`를 통과시켜요.
3. 필요한 파일만 커밋하고 원격 변경을 확인한 뒤 `main`을 푸시해요.
4. `node tests/deployment-check.cjs --wait`로 Pages 성공 커밋과 공개된 14개 자산의 내용이 일치하는지 확인해요.
5. `node tests/browser-check.cjs --live`로 실제 공개 사이트의 앱 이동·등록·오프라인 동작을 새 임시 브라우저 프로필에서 검증해요.

배포 확인은 기존 Git credential manager의 인증을 메모리에서만 사용하며 인증 정보를 파일이나 로그에 남기지 않아요. Git 배포는 Apps Script 재배포와 별개예요.

폰과 컴퓨터에서 같이 쓰는 가계부예요. 기록은 **내 구글 계정의 구글 시트**에 저장돼서, 다른 사람(이 앱을 만든 사람 포함)은 볼 수 없어요.

## 1. 내 구글 시트 만들기

1. [sheets.new](https://sheets.new)에 접속해서 새 시트를 만들고, 이름을 "가계부"처럼 지어요.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
3. 원래 있던 코드를 모두 지우고 [구글시트-동기화-코드.gs](구글시트-동기화-코드.gs) 내용을 통째로 복사해서 붙여넣어요. 파일을 열고 오른쪽 위 복사 버튼(📋)을 누르면 돼요.
4. 4번째 줄 `'여기에-비밀번호-입력'`을 **나만 아는 비밀번호**로 바꾸고 저장(💾)해요.
   ```js
   const SECRET = '나만-아는-비밀번호';
   ```

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누르고, 톱니바퀴(⚙)에서 **웹 앱**을 골라요.
2. 다음처럼 설정하고 **배포**를 눌러요.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (비밀번호를 아는 사람만 기록을 읽고 쓸 수 있어요)
3. 권한 요청이 나오면 내 계정을 골라요.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요. 직접 붙여넣은 코드라 괜찮아요.
4. 화면에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둬요.

## 3. 가계부에 연결하기

1. [플랫폼 주소](https://mano-lee.github.io/gagyebu/)를 열고 위쪽 **설정·백업**으로 가요.
2. **폰·컴퓨터 같이 쓰기** 칸에서 다음을 입력해요.
   - **비밀번호**: 1단계에서 정한 비밀번호
   - **내 구글 시트 따로 쓰기**를 눌러서 펼치고, **웹 앱 URL**에 2단계에서 복사한 주소
3. **연결하기**를 눌러요. 화면 위쪽에 `☁ 동기화됨`이 뜨면 성공이에요.
4. 플랫폼 홈에서 **가계부**를 열고 **가계부 설정**에서 **예산 기간 시작일**(월급날 등)과 **고정지출**도 입력해 두세요.

폰과 컴퓨터 등 **쓰려는 기기마다 3단계를 한 번씩** 해 주세요. 웹 앱 URL은 카카오톡 "나와의 채팅"으로 보내 두면 옮기기 편해요.

## 4. 폰 홈 화면에 앱으로 추가하기

- **크롬**: 오른쪽 위 ⋮ → **홈 화면에 추가** → **설치**
- **삼성 인터넷**: 주소창 옆 ⬇ 설치 아이콘, 또는 ≡ → **현재 페이지 추가 → 홈 화면**
- **아이폰 사파리**: 공유 버튼 → **홈 화면에 추가**

### 알아두면 좋은 점

- 기록은 구글 시트의 **`내역` 탭**에서 날짜순으로 볼 수 있어요. `_data` 탭은 앱이 쓰는 원본이라 직접 고치면 안 돼요.
- 인터넷이 안 될 때 기록해도 기기에 먼저 저장되고, 다시 연결되면 자동으로 시트에 올라가요.
- 비밀 모드(시크릿 모드)에서는 쓰지 마세요. 창을 닫으면 기기에 저장된 기록과 연결 정보가 지워져요.
- Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 URL이 바뀌지 않아요.
