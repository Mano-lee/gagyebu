# 내 생활

가계부와 냉장고를 한곳에서 사용하는 생활 플랫폼이에요. 처음 열면 **플랫폼 홈**에서 사용할 앱을 선택해요.

- **가계부**: 요약, 내역, 가계부 설정을 관리해요.
- **냉장고**: 보관 목록, 식재료 등록 대기, 소비·폐기 기록을 관리해요.
- **설정·백업**: 모든 앱의 구글 시트 연결과 백업을 함께 관리해요.

각 앱 상단의 **← 플랫폼 홈**으로 돌아올 수 있어요. 홈의 냉장고 카드에서 등록 대기·기한 임박 건수를 누르면 해당 화면으로 바로 이동해요. 휴대폰·브라우저의 뒤로 가기와 앞으로 가기도 지원해요. 앱 안에서 새로고침하면 해당 화면을 유지하고, 설치 앱을 기본 주소로 열면 플랫폼 홈에서 시작해요.

가계부 지출에서 식품을 체크하면 냉장고에 **식재료 등록 대기**가 생겨요. 제품별 금액을 나누지 않고 장보기 결제 한 건을 여러 식재료와 연결할 수 있어요.

### 냉장고 사용하기

냉장고 화면 위쪽에서 **냉동실·냉장실 그림과 오른쪽 실온 박스**로 보관 상태를 한눈에 확인해요. 각 공간에 보관 중인 품목 수와 기한 상태가 표시돼요. **임박**은 표시 기한까지 3일 이내, **기한 지남**은 지난 날짜이며, 기한을 입력하지 않은 제품은 별도로 표시해요. 그림을 누르면 해당 보관 장소의 식재료 목록으로 이동해요. 소비·폐기한 제품은 보관 현황에서 제외하고, 수량이 여러 개인 제품도 등록된 묶음 하나를 1개 품목으로 세어요.

1. 지출을 기록하면서 구매한 식품의 **냉장·냉동·실온**을 체크해요. 여러 개를 선택할 수 있어요.
2. **플랫폼 홈**의 냉장고 카드나 가계부 요약 화면에서 등록 대기를 확인해요. 냉장고 안의 **등록 대기** 메뉴에서도 볼 수 있어요. 이 알림은 앱 안에 표시돼요.
3. **식재료 등록하기**에서 제품 이름, 수량·단위, 보관 장소, 구매일, 표시된 기한, 개봉 여부를 입력해요. 구매일은 지출 날짜에서 가져와요.
4. **이 제품 저장하고 계속**으로 제품을 하나씩 저장해요. 중간에 닫아도 저장한 제품과 등록 대기는 남아요.
5. 모두 입력한 뒤 **등록 완료**를 눌러요. 실수로 체크했다면 **등록할 식재료 없음**으로 대기를 해제할 수 있어요.

같은 제품도 구매할 때마다 별도로 등록해 기한과 개봉일을 구분해요. 이미 가지고 있는 재료는 **직접 등록**할 수 있어요. **개봉·다 먹음·폐기**를 처리하고, 소비·폐기 기록에서 보관 중으로 복원할 수 있어요. 표시 기한 임박은 3일 이내이며, 기한이 지난 제품도 같은 목록에 표시돼요.

지출의 날짜·메모를 수정해도 대기는 중복 생성되지 않아요. 완료한 구매에 새 보관 종류를 체크하면 다시 대기에 표시돼요. 지출을 삭제하거나 식품 체크를 해제해도 이미 등록한 식재료는 남아요. 백업·복원·초기화는 가계부와 냉장고에 함께 적용돼요. 예전 가계부 전용 백업을 복원하면 냉장고는 빈 목록이 됩니다.

### 기존 사용자 업데이트

사이트 파일에 `fridge.js`, `fridge.css`, `platform.js`, `platform.css`가 추가됐어요. `index.html`, `sw.js`, `manifest.webmanifest`, 새 아이콘 파일과 함께 배포해요. 설치 앱의 표시 이름도 **내 생활**로 변경됐어요.

**동기화를 사용한다면 아래 절차로 Apps Script 코드도 갱신하세요.** 기존 `SECRET` 비밀번호는 유지하고 [구글시트-동기화-코드.gs](구글시트-동기화-코드.gs)의 새 내용을 적용한 뒤, **배포 → 배포 관리 → 수정 → 새 버전**으로 배포해요. 이후 사용하는 모든 기기에서 앱을 새로고침해 주세요. 새 서버 코드는 냉장고 데이터가 저장된 후 구버전 앱의 접근을 차단해 새 기록이 덮어써지는 것을 막아요. 구글 시트 원본과 JSON 백업에는 식재료가 포함되고, 보기용 `내역` 탭에는 기존처럼 가계부 지출·수입이 표시돼요.

개발 검증: Node.js에서 `node --test tests/fridge.test.cjs`를 실행해요. Chrome 또는 Edge가 설치되어 있다면 `node tests/browser-check.cjs`로 실제 등록 흐름, 반응형 화면, 오프라인 새로고침을 검증할 수 있어요. 브라우저 검증은 별도 임시 프로필과 가상 데이터만 사용하고, 화면 이미지는 Git에서 제외된 `.qa-preview/`에 남겨요.

### 아이콘과 Git 배포

플랫폼 아이콘은 초록 바탕에 크림색·금색의 네 앱 타일을 배치한 [벡터 원본](app-icon.svg)이에요. 설치용 192·512px PNG, 아이폰용 180px PNG, 탭용 32px PNG를 함께 제공해요. 원본을 수정한 뒤 `node tests/browser-check.cjs --render-icons`로 다시 렌더링할 수 있어요.

기존 배포는 `Mano-lee/gagyebu`의 `main` 브랜치 루트를 사용하는 GitHub Pages예요. 이후 변경 시에는 로컬 검증 후 커밋·푸시하고, 배포된 버전과 실제 사이트까지 확인해요. 이 작업 순서는 [AGENTS.md](AGENTS.md)에 유지해요.

1. `node tests/deployment-check.cjs --inspect`로 기존 배포 상태·설정을 확인해요.
2. 자동 테스트, 로컬 브라우저 검증, `git diff --check`를 통과시켜요.
3. 필요한 파일만 커밋하고 원격 변경을 확인한 뒤 `main`을 푸시해요.
4. `node tests/deployment-check.cjs --wait`로 Pages 성공 커밋과 공개된 12개 자산의 내용이 일치하는지 확인해요.
5. `node tests/browser-check.cjs --live`로 실제 공개 사이트의 앱 이동·등록·오프라인 동작을 새 임시 브라우저 프로필에서 검증해요.

배포 확인은 기존 Git credential manager의 인증을 메모리에서만 사용하며 인증 정보를 파일이나 로그에 남기지 않아요. Git 배포는 Apps Script 재배포와 별개예요.

폰과 컴퓨터에서 같이 쓰는 가계부예요. 기록은 **내 구글 계정의 구글 시트**에 저장돼서, 다른 사람(이 앱을 만든 사람 포함)은 볼 수 없어요.

## 1. 내 구글 시트 만들기

1. [sheets.new](https://sheets.new)에 접속해서 새 시트를 만들고, 이름을 "가계부"처럼 지어요.
2. 메뉴에서 **확장 프로그램 → Apps Script**를 열어요.
3. 원래 있던 코드를 모두 지우고 [구글시트-동기화-코드.gs](구글시트-동기화-코드.gs) 내용을 통째로 복사해서 붙여넣어요. 파일을 열고 오른쪽 위 복사 버튼(📋)을 누르면 돼요.
4. 4번째 줄 `'여기에-비밀번호-입력'`을 **나만 아는 비밀번호**로 바꾸고 저장(💾)해요.
   ```js
   const SECRET = '나만-아는-비밀번호';
   ```

## 2. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누르고, 톱니바퀴(⚙)에서 **웹 앱**을 골라요.
2. 다음처럼 설정하고 **배포**를 눌러요.
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자** (비밀번호를 아는 사람만 기록을 읽고 쓸 수 있어요)
3. 권한 요청이 나오면 내 계정을 골라요.
   "Google에서 확인하지 않은 앱" 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요. 직접 붙여넣은 코드라 괜찮아요.
4. 화면에 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 둬요.

## 3. 가계부에 연결하기

1. [플랫폼 주소](https://mano-lee.github.io/gagyebu/)를 열고 위쪽 **설정·백업**으로 가요.
2. **폰·컴퓨터 같이 쓰기** 칸에서 다음을 입력해요.
   - **비밀번호**: 1단계에서 정한 비밀번호
   - **내 구글 시트 따로 쓰기**를 눌러서 펼치고, **웹 앱 URL**에 2단계에서 복사한 주소
3. **연결하기**를 눌러요. 화면 위쪽에 `☁ 동기화됨`이 뜨면 성공이에요.
4. 플랫폼 홈에서 **가계부**를 열고 **가계부 설정**에서 **예산 기간 시작일**(월급날 등)과 **고정지출**도 입력해 두세요.

폰과 컴퓨터 등 **쓰려는 기기마다 3단계를 한 번씩** 해 주세요. 웹 앱 URL은 카카오톡 "나와의 채팅"으로 보내 두면 옮기기 편해요.

## 4. 폰 홈 화면에 앱으로 추가하기

- **크롬**: 오른쪽 위 ⋮ → **홈 화면에 추가** → **설치**
- **삼성 인터넷**: 주소창 옆 ⬇ 설치 아이콘, 또는 ≡ → **현재 페이지 추가 → 홈 화면**
- **아이폰 사파리**: 공유 버튼 → **홈 화면에 추가**

### 알아두면 좋은 점

- 기록은 구글 시트의 **`내역` 탭**에서 날짜순으로 볼 수 있어요. `_data` 탭은 앱이 쓰는 원본이라 직접 고치면 안 돼요.
- 인터넷이 안 될 때 기록해도 기기에 먼저 저장되고, 다시 연결되면 자동으로 시트에 올라가요.
- 비밀 모드(시크릿 모드)에서는 쓰지 마세요. 창을 닫으면 기기에 저장된 기록과 연결 정보가 지워져요.
- Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전**으로 다시 배포해야 URL이 바뀌지 않아요.
